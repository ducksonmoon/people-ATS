# User Management Page

## Overview

The User Management page provides a comprehensive interface for administrators and HR personnel to manage users within the system. This includes creating, updating, viewing, and deleting users with different roles (Admin, HR, Recruiter, Employee, Candidate).

## Features

- **Role-based Filtering**: Filter users by their roles (Admin, HR, Recruiter, Employee, Candidate)
- **Search Functionality**: Search for users by name or email
- **CRUD Operations**: Create, read, update, and delete users
- **Department Assignment**: Assign users to specific departments
- **Date Management**: Track hire dates and end dates for employment

## How to Access

The User Management page is accessible to users with Admin or HR roles. Navigate to it by:

1. Log in with an Admin or HR account
2. In the main navigation, click on the "Management" dropdown
3. Select "User Management" from the dropdown options

## Using the Page

### Viewing Users

- **All Users**: By default, the page shows all users
- **Filter by Role**: Use the tabs at the top to filter users by role
- **Search**: Use the search field to find specific users by name or email

### Creating a User

1. Click the "Add User" button
2. Fill in the required fields:
   - Name
   - Email
   - Password (and confirmation)
   - Role (Admin, HR, Recruiter, Employee, or Candidate)
3. Optionally add:
   - Department assignment
   - Hire date
4. Click "Create" to save the new user

### Updating a User

1. Find the user in the table
2. Click the edit (pencil) icon in the Actions column
3. Update the desired fields
4. Click "Update" to save changes

### Deleting a User

1. Find the user in the table
2. Click the delete (trash) icon in the Actions column
3. Confirm deletion in the dialog that appears

## Permissions

- **Admin users**: Can manage all users, including other admins
- **HR users**: Can manage recruiters, employees, and candidates, but not admin users

## Notes

- Password fields are only required when creating a new user
- When updating a user, leave the password blank if you don't want to change it
- Deleting a user cannot be undone - use with caution

## Troubleshooting

If you encounter any issues:

1. Check that you have the correct permissions (Admin or HR role)
2. Refresh the page if data isn't loading correctly
3. Contact the system administrator if problems persist
